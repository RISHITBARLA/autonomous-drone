# AUTONOMOUS-DRONE

Autonomous QR Code Detection and Mission-Based Drone System.

## Hardware
- Raspberry Pi 4
- Pixhawk 2.4.8
- S500 Quadcopter Frame
- IMX477 Camera

## Technology
- Python
- Flask
- OpenCV
- MAVLink
- HTML, CSS, JavaScript

## Main Modules
- Flight Controller Communication
- Computer Vision
- QR Code Detection
- Mission Management
- Geofence Management
- Web Ground Station
